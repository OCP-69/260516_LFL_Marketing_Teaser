# E-Mail nach interpack — Zwei Ansätze (Warm, Mouaz-Bezug)

**Stand:** 2026-06-09  
**Kontext:** Kollege **Mouaz Al-Qudsi** (CTO, LoopForgeLab) war auf der **interpack 2026** mit Sales-Kollegen der Ziel-OEMs im Gespräch und hat Visitenkarten eingesammelt (`01_InMails_Interpack_Personalisiert.md`, Foto `04_Outreach/Kontakte/Pictures/`).  
**Ihr Kanal:** E-Mail an **CEO/GF oder Engineering** (nicht LinkedIn) — längerer Text, optional Anhang.  
**Ziel:** Einen Schritt über den Messe-Kontakt hinaus — **Forge Engine** vorstellen und **Erstgespräch** (15–25 Min) vereinbaren.

---

## Abgrenzung zum reinen Cold-Outreach

| | Cold (`Einsatzbereit_Email/01–03`) | **Warm interpack (hier)** |
|---|-------------------------------------|---------------------------|
| Bezug | Kein vorheriger Kontakt | Mouaz + interpack + ggf. namentlicher Sales-Kontakt |
| Touch 1 | Nur Frage, kein Produkt | Kurze Modell-Einordnung erlaubt |
| Anhang | Nein | Ansatz B: Teaser ja |
| Termin | Erst Touch 3 | **Touch 1:** weicher Terminvorschlag erlaubt |
| Calendly | Touch 4 | Optional als **zweite Option** neben „Sie nennen Zeit“ |

**Nicht erfunden:** Keine konkreten Zitate vom Messestand, die nicht dokumentiert sind. Token `[Mouaz_Kontakt]` nur setzen, wenn Name auf Visitenkarte steht.

---

## Zwei Ansätze — Kurzvergleich

| | **Ansatz A — Brücke + Dialog + Termin** | **Ansatz B — Modell + Teaser + Termin** |
|---|----------------------------------------|----------------------------------------|
| **Tempo** | Etwas langsamer, höhere Antwortqualität | Etwas schneller, weniger Runden |
| **Länge** | ~180–220 Wörter | ~140–170 Wörter + Anhang |
| **Forge Engine** | 2 Sätze, kein Feature-Listing | 4 Bullet-Points, klarer Nutzen |
| **Frage** | Eine scharfe Einordnungsfrage bleibt | Eine Ja/Nein-Frage zur Relevanz |
| **Anhang** | Nein (Teaser nach Antwort) | **Ja** — `Variante E Interpack` (HTML/PDF) |
| **CTA** | 20 Min, Sie nennen Zeit **oder** Calendly | 20 Min, zwei konkrete KW-Vorschläge + Calendly |
| **Wann** | GF, skeptische Konzerne, wenn Mouaz-Kontakt nur Sales war | Engineering, Mittelstand, wenn Messe-Gespräch substanziell war |
| **Risiko** | Kann „zu vorsichtig“ wirken nach Messe | Kann „zu pitchig“ wirken ohne Mouaz-Namen |

**Empfehlung:** Firmen **mit Visitenkarte + Engineering-Prio** → Ansatz B (z. B. Handtmann, KÖRA, Bausch+Ströbel). **Konzern / nur Sales-Kontakt** → Ansatz A (z. B. Syntegon, Krones, Multivac).
